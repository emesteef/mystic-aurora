# Podgląd stron PDF – „7 dni powrotu do siebie”

Obrazy z tego folderu pokazują się automatycznie w sekcji „Zajrzyj do środka”
na stronie `/7-dni-powrotu-do-siebie`. Nie trzeba zmieniać kodu.

- Format: `.webp`
- Nazwy: `dzien-1-strona-1.webp`, `dzien-1-strona-2.webp`, … (kolejność według nazwy)
- Proporcje: strona A4 pionowo (1 : 1,414), np. 1000 × 1414 px
- Wstaw tylko prawdziwe strony z materiału PDF.

Dopóki folder nie zawiera obrazów `.webp`, strona pokazuje dwa neutralne placeholdery „Podgląd materiału”.
